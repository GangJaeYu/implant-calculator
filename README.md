# 임플란트 식립 거리 계산기

치아 근원심폭으로 임플란트 픽스처 중심 위치와 인접 자연치·임플란트와의 거리를 계산하는 단일 페이지 도구입니다.

- 상악/하악/상하악 배치도, 간격 부족 경고와 원인, 해부학 확인 항목(근거 문헌 포함)
- 케이스 저장·불러오기(브라우저 localStorage, 서버 전송 없음)
- PNG / PDF 저장(인쇄용)
- 한 번 열면 오프라인에서도 동작(PWA). 모바일에서는 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 설치

수술 계획 참고용이며, 실제 위치는 CBCT·모형·수술 가이드로 확인해야 합니다.
